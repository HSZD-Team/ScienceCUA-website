ScienceCUA

ScienceCUA is a two-stage framework that distills human-authored software manuals and web pages into executable, reusable skills, and keeps evolving them through real executions — giving computer-use agents the application-specific expertise that scientific software demands.

01 / Motivation

Rich documentation. Sparse task-relevant knowledge.

Scientific software comes with extensive manuals and tutorials, but a task often depends on only a few operational details. In our ScienceBoard experiments, directly injecting raw documentation offers modest gains in task success while substantially increasing execution time. ScienceCUA organizes this knowledge into focused, reusable Skills and queryable References.

02 / Pipeline

Construct from resources. Evolve through execution.

ScienceCUA first builds a library from software documentation, then refines it using feedback from real software execution. Skills and References evolve outside the model parameters, and candidate knowledge updates undergo independent validation before entering the final library.

  1. Stage 1

    Resource-to-Skill Construction

    Organize PDF/HTML documentation into traceable evidence. Extract shared References and induce reusable Skills through task discovery and trajectory inference.

  2. Stage 2

    Execution-Guided Skill Evolution

    Use failure history to guide exploration, revise faulty knowledge or add source-supported entries, and validate candidates in reset environments and fresh sessions.

03 / Skills & References

Reusable workflows. Knowledge on demand.

Skills provide reusable, task-level procedures. References supply shared syntax, parameters, and constraints for on-demand lookup. Explore six examples from the ScienceCUA library, pairing a concrete workflow with related software knowledge.

Celestia

Astronomy & simulation

SkillReusable procedure

Find and observe an eclipse

Locate a solar or lunar eclipse, travel to the event, and control its progression.

  1. Enable eclipse shadows

    Open Render → View Options and enable Eclipse Shadows.

  2. Define the search

    Open Navigation → Eclipse Finder and choose the type, planet, and date range. For Jupiter through Neptune, keep the range to one year or less.

  3. Travel to the event

    Click Compute, select an eclipse, then use the set-date-and-GoTo button and close the dialog.

  4. Control and restore time

    Press L to accelerate. Use the backslash key to restore the real-time rate, then Time → Set Time → Set to Current time to return to the present.

GRASS GIS

Geospatial analysis

SkillReusable procedure

Display a filtered, labeled vector map

Select vector features by attribute and render their geometry with readable labels.

  1. Choose the map

    Prepare d.vect with the vector map name and display=shape in an active graphics frame.

  2. Filter the features

    Use cats for categories or where for an SQL condition, omitting the WHERE keyword.

  3. Set labels and colors

    Choose attribute_column for labels. Set feature and fill colors, or use -c for category-based random colors.

  4. Render the selection

    Run the assembled command. The library includes this example using the Spearfish soils map.

Documented command
d.vect -c map=soils where="label='VBF'" display=shape attribute_column=label

ChimeraX

Molecular visualization

SkillReusable procedure

Show a selected residue as sticks

Use interactive selection to change the representation of one residue in a displayed structure.

  1. Select an atom

    With the default mouse assignment, Ctrl-click an atom in the desired residue to replace the previous selection.

  2. Expand to the residue

    Keep focus in the graphics window and press the up arrow once.

  3. Apply the representation

    Run style sel stick. The sel target limits the command to the current selection.

Command for the current selection
style sel stick

Lean 4

Formal reasoning

SkillReusable procedure

Prove an equality by induction

Prove 0 + n = n by following the recursive structure of natural-number addition.

  1. State the goal

    Introduce n : Nat and begin the theorem's tactic proof with by.

  2. Split the cases

    Use induction n with to create zero and successor branches, naming the induction hypothesis ih.

  3. Close the base case

    Use rfl when the zero case reduces to reflexive equality.

  4. Rewrite the successor case

    Apply the successor equation and then the induction hypothesis with rw [Nat.add_succ, ih].

Proof from the library
namespace Hidden

theorem zero_add (n : Nat) : 0 + n = n := by
  induction n with
  | zero => rfl
  | succ n ih => rw [Nat.add_succ, ih]

end Hidden

TeXstudio

Scientific writing

SkillReusable procedure

Keep pdfLaTeX output in a build folder

Route generated files into a subfolder and keep TeXstudio's log and PDF lookup in sync.

  1. Open configuration

    Open Options → Configure TeXstudio and show advanced options if the settings are hidden.

  2. Set the output folder

    Under Commands, add -output-directory=build to the pdfLaTeX command.

  3. Update the log search path

    Under Build → Build options, add build as an additional search folder for log files.

  4. Update the PDF search path

    Add build for PDF files too. The documented Clean Auxiliary Files dialog does not clean files stored in a different folder this way.

pdfLaTeX command argument
-output-directory=build

Reusable knowledge for software agents

Related work explores complementary ways to make operational knowledge available to agents: VisualSkill combines application-specific guides with visual references, while SkillFoundry compiles heterogeneous scientific resources into validated skill packages. In our evaluation, ScienceCUA’s source-grounded workflows and shared lookup knowledge improve average task success across both execution settings.

ScienceCUA / Build Skills

Welcome to ScienceCUA Build Skills

  1. Build knowledge from documentation

    Upload human-authored PDF documents or provide HTML web pages, and let ScienceCUA organize their software knowledge into reusable Skills and References for on-demand lookup.

  2. Configure your API key

    The online service requires your own model provider API key. We take your key’s security seriously and are committed to protecting it. We will not publish your key or disclose it to unauthorized third parties.

  3. Self-hosting is also available

    If you prefer to run the system in your own environment, you can deploy our open-source code locally and manage your API keys and input materials yourself.

  4. Feedback and contributions are welcome

    We’re sorry if our pipeline or its outputs fall short of your expectations. Please open a GitHub Issue to report problems or share suggestions. Code improvements and Pull Requests are also welcome as we continue improving ScienceCUA together.

  1. 从文档构建知识

    上传人类编写的 PDF 文档或提供 HTML 网页，让 ScienceCUA 将其中的软件知识整理为可复用的 Skills 和可按需查询的 References。

  2. 配置您的 API 密钥

    在线体验需要您填写自己的模型服务 API 密钥。我们重视您的密钥安全，并承诺妥善保护，不公开或向未经授权的第三方披露您的密钥。

  3. 也可选择本地部署

    如果您更希望在自己的环境中使用，欢迎通过已开源的代码进行本地部署，自行管理 API 密钥和输入资料。

  4. 欢迎反馈与贡献

    如果我们的流程或生成结果未达到您的预期，我们深感抱歉。欢迎在 GitHub 提交 Issue，反馈问题或提出建议；也欢迎改进代码、提交 Pull Request，与我们一起完善 ScienceCUA。
